# Product Doctrine

1. Markdown files are always source of truth.
2. SQLite is a cache, never the only copy of user notes.
3. Plugins are permissioned by default.
4. AI is local-first by default.
5. Sync must become open, encrypted, and self-hostable.
6. UI must remain fast under large vaults.
7. Architecture must stay modular and GitHub-friendly.

LATTICE should feel like a serious local knowledge environment, not a chatbot wrapper or cloud dashboard.
